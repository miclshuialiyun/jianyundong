本条款是您（以下称「用户」）与「简·运动 — 跑步训练负荷记录」（软件标识 cn.jianyundong.app，以下称「本应用」）之间，就使用本应用达成的协议。您下载、安装或使用本应用，即表示您已阅读并同意本条款的全部内容；如不同意，请停止使用并卸载本应用。

一、服务内容

本应用是一款本地优先的跑步与训练记录工具，为您提供：

  • GPS 轨迹、距离、配速、时长与心率的记录（iPhone 与 Apple Watch）；
  • 训练负荷指标（CTL 长期负荷、ATL 短期负荷、TSB 状态）的计算与趋势展示；
  • 训练计划、节拍器与每公里语音播报；
  • 跳绳计数（基于设备运动传感器的估算值，手机端与 Apple Watch 端均支持）；
  • 与系统「健康」App 的数据读取与写入；
  • 运动记录的本地存储与 CSV / JSON / GPX 格式导出。
健康声明：本应用提供的训练负荷数值与建议，均基于公开的训练学模型进行估算，不构成医疗意见或诊断。如您患有心血管疾病或其他健康问题，请在专业医师指导下进行运动。运动中请注意人身安全并遵守交通规则。

二、免费功能与订阅范围

基础记录、历史查看与全量数据导出永久免费，不因是否订阅而改变。订阅仅用于解锁进阶功能（多套分享卡模板、分段配速着色与爬升剖面、跑鞋多双追踪、自定义训练计划、去水印、不限次节拍器、高级语音播报等）。应用内订阅页列有完整的「免费 / 会员」能力对照表。

五、恢复购买与退款

  • 恢复购买：更换设备或重新安装后，可在应用内「设置 → 订阅 → 恢复购买」恢复已购权益，系统会通过您的 Apple 账户核验。
  • 退款：所有订阅由 Apple 处理，退款须经 Apple 审核。您可在 reportaproblem.apple.com 提交申请，也可在应用内「设置 → 订阅 → 申请退款」发起。若 Apple 未通过，您可联系支持邮箱，我们将按未使用天数补偿相应会员时长。
  • 卸载应用不会自动终止订阅，仍需按第三条主动取消。

六、数据归属与存储

您的运动数据归您所有。数据默认仅存储在您自己的设备上，我们没有服务器，不会上传您的运动记录。您可随时在应用内将数据导出为 CSV / JSON / GPX 并自行保存。卸载应用会删除设备上的本地数据，请先导出备份。详见 隐私政策。
